# Beginner Level Exercises

A collection of foundational programming exercises and small projects designed to practice core logic, syntax, and problem-solving skills in Java. This repository serves as a personal log of my journey in learning software engineering basics.

## Contents

This repository includes various solutions to common beginner programming problems:

- **Logic Exercises:** Practice with loops, conditionals, and decision-making structures.
- **Algorithms:** Basic implementation of standard algorithms (e.g., sorting, finding patterns).
- **Data Manipulation:** Working with arrays, loops, and basic data structures.

## Objectives

- Strengthening mastery of Java syntax.
- Understanding control flow and algorithm logic.
- Building a consistent habit of coding and version control.

## Technologies

- **Language:** Java
- **Tools:** IntelliJ IDEA
- **Version Control:** Git & GitHub

## How to Navigate

Each folder corresponds to a specific challenge or topic. You can find the main logic within the `.java` source files in each directory.
